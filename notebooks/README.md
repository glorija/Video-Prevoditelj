# Notebooks

This directory contains reproducible Kaggle notebooks used by Video Prevoditelj HR.

## Naming

Use descriptive names related to the purpose of the notebook.

Examples:

- `videoprevoditeljhr-klonaudio-clean.ipynb`
- `videoprevoditeljhr-diarization.ipynb`
- `videoprevoditeljhr-pipeline-test.ipynb`

## Rules

A notebook should preserve the important setup, processing steps, checks, and outputs needed to reproduce its work.

Do not store large WAV, MP4, or model files inside this directory.

Large artifacts belong in Kaggle Datasets or the appropriate model repository.
